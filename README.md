# Karnetik

Application mobile de carnet d'entretien automobile digital, avec un historique **transmissible** entre propriétaires (l'historique suit le véhicule, pas le propriétaire).

## Structure du mono-repo

- `api/` — Backend Laravel (API-only), PostgreSQL, Sanctum pour l'auth
- `mobile/` — Application mobile React Native (Expo) — à venir

## Stack technique

- **Backend** : Laravel (API-only)
- **Base de données** : PostgreSQL
- **Mobile** : React Native (Expo), iOS + Android
- **Auth** : Laravel Sanctum
- **Hébergement** : Infomaniak (Suisse), auto-hébergé
